# 英雄连2 macOS 汉化助手

让 Mac 上的《英雄连2》更方便地使用中文。

本仓库仅用于项目介绍与咨询，不公开提供安装包、源码或注册码。

## 功能

- **自动搜索游戏**：读取 Steam 游戏库配置，查找自定义游戏库、常见应用目录及挂载磁盘的常见安装位置；多个结果可选择，未找到时支持手动选择。
- **图形界面激活**：在助手窗口中输入注册码，不需要手动执行终端命令。
- **启动汉化版或原版**：在同一个窗口中选择启动方式；原游戏的发行渠道验证仍需正常完成。
- **独立汉化副本**：不覆盖原游戏资源。
- **移除汉化副本**：将当前用户的汉化副本移到废纸篓，保留原游戏、存档、授权、助手应用和安装资源。

## 当前版本

**0.6.1 · macOS 汉化测试版**

自动搜索不是全盘扫描；未挂载、无读取权限或位于未索引的任意目录时，可能需要手动选择。找到游戏目录后，启动汉化前仍会校验资源版本。

## 使用流程

1. 通过下方淘宝入口联系，先确认电脑配置与游戏版本是否适配。
2. 获得安装包和注册码后，安装并打开「英雄连2 汉化助手」。
3. 点击「自动搜索」，或手动选择游戏位置。
4. 点击「输入注册码…」，按提示完成联网激活。
5. 点击「启动汉化版」。需要原版时，点击「启动原版」。

## 使用须知

- 需要自行安装兼容版本的 Mac 版《英雄连2》；汉化测试包不包含游戏本体。
- 默认一码一台电脑，首次激活和每次启动汉化均需联网。换机需联系发布者处理。
- 原版启动不受汉化授权限制，但仍需满足游戏自身与发行渠道的要求。
- 助手和授权客户端包含 Intel（x86_64）与 Apple Silicon（arm64）架构；最低系统目标为 Intel macOS 10.15、Apple Silicon macOS 11。
- 已完成本机功能与隔离测试；实体 Intel Mac、跨电脑安装及独立发行版尚未完成验收，购买前请先确认适配情况。
- 汉化仍在测试，尚未完成所有章节、DLC、多人页面及图片文字的逐项验收；部分字体外观也与原版不同。
- 当前应用仅作本地 ad-hoc 签名，尚未完成 Developer ID 签名与 Apple 公证。
